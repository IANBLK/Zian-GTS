# Zian GTS feature plan

## Baseline
- /gts listing browser
- /gts sell
- /gts claim
- listing expiration
- purchase confirmation
- filters and sorting
- persistent active listings

## Aventura additions
- Spanish UI and messages
- Keep "Shiny" terminology
- Alpha, Shiny, Legendary and Legendary Shiny filtering
- AVECOINS economy support
- Persistent sale history for moderation/investigation
- Administrative history lookup and controlled deletion

## Compatibility target
Minecraft 1.21.1, NeoForge, Java 21, Cobblemon 1.8+.
